# PontoAll-Api

Repositório para o código da api do sistema PontoAll

## Modelos Dlib Utilizados

Crie uma pasta chamada FaceRecognition dentro de PontoAll.WebAPI
Baixe os seguintes modelos e extraia cada um para dentro dessa pasta

- [Modelo de landmarks (5 pontos faciais)](https://github.com/davisking/dlib-models/blob/master/shape_predictor_5_face_landmarks.dat.bz2)
- [Modelo de landmarks (68 pontos faciais)](https://github.com/davisking/dlib-models/blob/master/shape_predictor_68_face_landmarks.dat.bz2)
- [Modelo de reconhecimento facial (ResNet)](https://github.com/davisking/dlib-models/blob/master/dlib_face_recognition_resnet_model_v1.dat.bz2)
- [Modelo de reconhecimento facial (mmod)](https://github.com/davisking/dlib-models/blob/master/mmod_human_face_detector.dat.bz2)
